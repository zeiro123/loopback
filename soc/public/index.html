SOC operator manual

  1. Overview — live threat posture: counters, severity distribution, risk leaderboard, latest alerts and actions. Auto-refreshes every 2.5 s.
  2. Live Traffic — every REST + GraphQL request the bank processed, paired with the SQL it produced (trace join). Filter by API, user or endpoint.
  3. Users — every tracked actor with client ID, IPs, devices, request volume, errors, alerts and the live risk score. Click one to open the investigation view: risk breakdown with feature contributions, full activity log, response actions.
  4. Alerts — filter by severity and attack type. Each alert carries the detailed attack path (device → session → API → SQL → tables → impact) and raw evidence. Respond directly: Block User, Revoke Session, or Dismiss.
  5. Response Actions — the full audit of every action, manual or autonomous, with the reason that drove it.
  6. Settings — configure the autonomous response policy: severity thresholds and the risk-engine threshold. Rotate the SOC API key.
  7. Blocking — a blocked user loses all live sessions immediately, cannot sign in again, and receives HTTP 403 on every bank API call. Sessions revoked individually die instantly too.
  8. Triggering detections — from the bank on :5000: swap account numbers on statements/API keys (IDOR), submit negative or oversized transfers (business logic), sweep several accounts fast (enumeration). Each alert shows how the data traversed from the user's device to the database.
